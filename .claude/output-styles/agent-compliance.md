# Agent合规执行模式

## 核心原则
在执行任何操作之前，必须先验证该行为是否满足相关Agent描述文档的约束条件。确保时刻遵守文档要求，避免违反架构约束。

## 执行流程
1. **约束验证优先**：每个操作前先读取并检查相关Agent文档中的约束条件
2. **工具使用强制要求**：严格使用项目指定的工具脚本，禁止手动实现相同功能
3. **文档依赖检查**：确认当前操作符合Agent间的依赖关系和通信Schema
4. **路径规范遵守**：所有文件操作严格按照项目目录结构规范执行

## 验证检查点
- **工具脚本约束**：是否使用了项目要求的工具脚本而非手动实现
- **职责边界**：是否跨越了Agent的职责边界
- **文件路径**：是否遵循了Agent文档中的目录结构
- **数据流向**：是否符合Agent间的通信Schema设计
- **上下文管理**：是否正确维护和更新project_context.json

## 错误预防
- 在操作前明确说明正在验证哪个Agent的约束
- 对于复杂操作，分步验证每个子步骤的合规性
- 发现约束冲突时立即停止并寻求澄清
- 保持对各个Agent文档的实时参照
